¿Qué son los metadatos?

Los metadatos son datos que describen una fotografía. Pueden guardar información sobre el dispositivo, la fecha, la configuración de la cámara y, en algunos casos, el lugar exacto donde fue tomada.

INFORMACIÓN OCULTA

Una fotografía puede revelar más de lo que ves

Cuando observamos una imagen solamente vemos sus píxeles, pero el archivo puede contener información adicional que no aparece directamente en la fotografía.

Estos datos pueden ser útiles para organizar imágenes, pero también podrían afectar la privacidad si se comparten sin revisarlos.

DATOS FRECUENTES

¿Qué información puede contener una imagen?

⌖

Ubicación

Las coordenadas GPS pueden indicar el lugar exacto donde se tomó una fotografía.

◷

Fecha y hora

Pueden ayudar a establecer cuándo ocurrió una actividad y contribuir a identificar rutinas.

▣

Dispositivo

La marca, el modelo, el lente y el software pueden describir el equipo utilizado.

⚙

Configuración

Incluye datos técnicos como ISO, apertura, flash, exposición y distancia focal.

✎

Autor y descripción

Algunos archivos pueden contener nombres, comentarios, derechos de autor o descripciones.

↻

Modificaciones

Pueden aparecer fechas de edición, programas utilizados y otros datos relacionados con el origen del archivo.

NIVELES DE PRIVACIDAD

¿Cómo clasifica ZERO TRACE los riesgos?

🔴 Riesgo alto

Información como las coordenadas GPS puede revelar lugares relacionados contigo.

🟠 Riesgo medio

Fechas, horas, descripciones o datos de autor pueden ayudar a reconstruir actividades o identidades.

🟡 Riesgo variable

El impacto depende del contenido y de cómo se combine con otros datos.

🟢 Riesgo bajo

La resolución o la configuración de cámara suelen tener poco impacto por sí solas.

PROTÉGETE

Antes de compartir una fotografía

  1. Revisa la ubicación. Comprueba si la fotografía contiene coordenadas GPS.
  2. Observa el nombre del archivo. Evita nombres que revelen personas, lugares o actividades.
  3. Elimina los metadatos. Crea una copia limpia antes de publicar o enviar la imagen.
  4. Verifica el resultado. Analiza nuevamente la copia para comprobar los datos restantes.
  5. Conserva el archivo original. Trabaja siempre con una copia para evitar perder información.
