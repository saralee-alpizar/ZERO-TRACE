¿Qué son los metadatos?

Son datos que pueden almacenarse dentro de una fotografía, como la fecha, la cámara utilizada, la configuración de captura y, en algunos casos, las coordenadas GPS.

⌖

Ubicación

Algunas fotografías pueden guardar el lugar exacto donde fueron tomadas.

◷

Fecha y hora

Estos datos pueden contribuir a identificar actividades, horarios o rutinas.

▣

Dispositivo

La marca, el modelo y el software pueden complementar un perfil sobre el propietario.
